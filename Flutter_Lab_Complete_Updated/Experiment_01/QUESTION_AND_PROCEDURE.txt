Working With Widgets and Layouts

REG. NO:
URK23CS1230

Objective:
To develop a Flutter application using basic widgets and layout widgets such as
Container, Row, Column, Expanded, Card, and ListView.
Tools/Software Required:
- Flutter
Description:
This experiment introduces basic Flutter widgets used to build a student profile interface.
Widgets such as Column, Row, Container, Card, ListTile, and ListView are used to organize UI elements.
It demonstrates layout arrangement, spacing, icons, cards, and displaying multiple items in a list.
Procedure:
Step 1 – Check Flutter installation
Open Terminal:
flutter doctor
Check whether Flutter is installed correctly.
Then check the available devices:
flutter devices
Step 2 – Create a Flutter project
flutter create widget_layout
Move into the project:
cd
widget_layout
Open in VS Code:
code .
Step 3 – Run the default application
flutter run
Step 4 – Open lib/main.dart
Delete the existing code.
Create the basic Flutter application:
import 'package:flutter/material.dart';
void main() {
runApp(const MyApp());
}
class MyApp extends StatelessWidget {
const
MyApp({super.key});
@override
Widget build(BuildContext context) {
return
MaterialApp(
debugShowCheckedModeBanner: false,
home: Scaffold(
appBar: AppBar(
title: const Text('Student Profile'),
),
body: const Center(
child: Text('Welcome to Flutter'),
),
),
);
}
}
