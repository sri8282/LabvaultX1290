Add Interactivity to App – Input and
Forms

REG. NO:
URK23CS1230

Objective:
To create an interactive Flutter form with input fields and
validation.
Tools/Software Required:
- Flutter
Description:
This experiment introduces interactive Flutter forms using TextFormField and form validation.
Input fields are created for student name, email, and password with suitable properties.
A submit button validates the form and displays a confirmation message using SnackBar.
Procedure:
Step 1
Create project:
flutter create student_form
cd student_form
code .
Step 2
Open:
lib/main.dart
Step 3 – Create Form
Create:
final _formKey = GlobalKey<FormState>();
Step 4 – Add TextFormField
TextFormField(
decoration: const InputDecoration(
labelText: 'Student Name',
),
validator: (value) {
if (value == null || value.isEmpty) {
return 'Enter student name';
}
return null;
},
),
Step 5 – Add email field
TextFormField(
decoration: const InputDecoration(
labelText: 'Email',
),
keyboardType: TextInputType.emailAddress,
),
Step 6 – Add password
TextFormField(
obscureText: true,
decoration: const InputDecoration(
labelText: 'Password',
),
),
Step 7 – Add Submit button
